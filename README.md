# Sheet Metal Formed Bracket

## Project Overview

This project showcases a 3D mechanical design of a formed sheet metal bracket, created using **SolidWorks**.

The design features two parallel mounting plates connected by a curved formed geometry, including mounting holes and elongated slots.

## Design Features

- 3D Sheet Metal Modeling
- Curved and formed geometry
- Mounting holes
- Elongated slots
- Mechanical CAD design
